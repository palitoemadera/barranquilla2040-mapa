# Barranquilla 2040: mapa de propuestas

Mapa interactivo de las propuestas del StoryMap *Barranquilla 2040* (Pablo Madera Granados, 2026).
Cada proyecto tiene su color y se puede prender o apagar desde la leyenda; al tocar una línea o un punto se lee qué es y de dónde sale.

- `index.html`: el mapa (Leaflet 1.9.4 incluido en el archivo, mapa base de OpenStreetMap en gris).
- `propuestas.geojson`: los datos.
- `mapa_propuestas.png`: versión fija para el StoryMap.

Los trazados de metro, el tren de cercanías y el soterrado son esquemáticos; las estaciones tienen ubicación ilustrativa.
Datos base: © colaboradores de OpenStreetMap (ODbL).
